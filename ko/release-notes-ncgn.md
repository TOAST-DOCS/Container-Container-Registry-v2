<a id="september-5-2024"></a>
### 2024. 09. 05. { #september-5-2024 }

<a id="september-5-2024-added-features"></a>
#### 기능 추가

* 이미지 서명 목록을 조회할 수 있습니다.

<a id="june-4-2024"></a>
### 2024. 06. 04. { #june-4-2024 }

<a id="june-4-2024-added-features"></a>
#### 기능 추가
* 미서명 이미지 배포 차단 기능이 추가되었습니다.

<a id="june-4-2024-feature-updates"></a>
#### 기능 개선
* 이미지 정리/보호 정책에서 `/`이 포함된 이미지도 식별할 수 있도록 수정하였습니다.
* 아티팩트 조회 항목을 확장하였습니다.
* 이미지 정리 정책의 개수 제한이 없도록 수정하였습니다.

<a id="march-5-2024"></a>
### 2024. 03. 05. { #march-5-2024 }

<a id="march-5-2024-added-features"></a>
#### 기능 추가
* NCR 콘솔에서 발생한 이벤트를 CloudTrail에서 확인할 수 있습니다.

<a id="march-5-2024-feature-updates"></a>
#### 기능 개선
* 이미지 키워드 검색이 가능하도록 수정하였습니다.

<a id="december-5-2023"></a>
### 2023. 12. 05. { #december-5-2023 }

<a id="december-5-2023-added-features"></a>
#### 기능 추가
* Public URI 사용 여부를 설정할 수 있는 기능을 추가하였습니다.
* 이미지 업로드만 할 수 있는 `Image Uploader` 권한이 추가되었습니다.

<a id="september-12-2023"></a>
### 2023. 09. 12. { #september-12-2023 }

<a id="september-12-2023-added-features"></a>
#### 기능 추가

* 이미지의 신뢰 기능을 추가하였습니다.

<a id="september-12-2023-feature-updates"></a>
#### 기능 개선

* OCI 아티팩트를 관리할 수 있는 기능이 추가되었습니다.
* Quota 기능이 추가되었습니다.

<a id="february-13-2023"></a>
### 2023. 02. 13. { #february-13-2023 }

<a id="february-13-2023-added-features"></a>
#### 기능 추가

* Private URI 기능 추가
    * 인터넷 게이트웨이에 연결되지 않은 인스턴스에서 NCR 서비스를 이용할 수 있는 Private URI 기능을 추가하였습니다.
    * 자세한 내용은 [Private URI 사용 가이드](./user-guide-ngsc/#private-uri)를 참고하십시오.

<a id="february-13-2023-feature-updates"></a>
#### 기능 개선

* 리전 간 복제 기능을 제외하였습니다.

<a id="january-25-2022"></a>
### 2022. 01. 25. { #january-25-2022 }

<a id="january-25-2022-bug-fixes"></a>
#### 버그 수정
* 간헐적으로 서비스 활성화가 실패하던 문제를 수정하였습니다.
* 토큰의 유효시간이 의도한 것보다 짧게 설정되었던 문제를 수정했습니다.
* 웹훅 생성 시 잘못된 엔드포인트로 인한 오류 메시지를 세분화하였습니다.


<a id="november-23-2021"></a>
### 2021. 11. 23. { #november-23-2021 }
<a id="november-23-2021-new-service-release"></a>
#### 신규 서비스 출시
* 기존 Container Registry 서비스를 개선하여 보다 안정적이고 쾌적한 환경을 제공합니다.
* 기존 Container Registry 서비스에서 부족하였던 점을 보완하여 다양한 기능을 제공합니다. 지원하는 기능은 지속적으로 업데이트될 예정입니다.
